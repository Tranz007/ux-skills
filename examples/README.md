# Example project context

These fictional examples show the shape of `.ux/` after `setup-ux`. They are intentionally small.

- [`greenfield`](greenfield/.ux/INTENT.md) starts from a product idea and keeps unsupported claims visibly uncertain.
- [`existing-product`](existing-product/.ux/INTENT.md) starts from an established repository and separates observable behavior from documented intent.

The examples are not templates to copy mechanically. Real projects should contain only useful context and should point to authoritative sources rather than duplicating them.

A project's default core is:

```text
.ux/
├── INTENT.md
├── CONTEXT.md
├── DESIGN-SYSTEM.md
└── DECISIONS.md
```

Additional files should appear only when density, repeated use, or independent ownership justifies them.
